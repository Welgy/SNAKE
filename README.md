# Snake Game (C++)

Простая консольная змейка на C++.

## Управление
- ↑ / ← / ↓ / → — движение

## Что реализовано
- Движение змейки по полю
- Рост при поедании еды
- Проигрыш при столкновении со стеной/собой

## Запуск
g++ main.cpp -o snake -lncurses

./snake
